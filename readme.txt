A professional SaaS-style Recipe Builder system for WooCommerce. Transform products into beautiful, structured recipe pages.

== Description ==

Dev ChefPress for WooCommerce adds a powerful Recipe Builder to your WooCommerce product pages. Using a modern, intuitive admin interface, you can build rich recipe content including:

* Hero section with ratings, cooking time & subtitle
* Nutrition quick-bar and full nutrition table
* Ingredient groups with drag-and-drop reordering
* Step-by-step cooking instructions with images and tips
* Allergen information
* Recipe tags/labels
* Before You Start notes

**Features:**
* Modern SaaS-style admin UI (no page reloads)
* Drag-and-drop repeaters (SortableJS)
* Nested ingredient groups
* WordPress Media Library integration
* Schema.org structured data markup
* Clean, responsive frontend templates
* Theme override support
* WooCommerce HPOS compatible
* OOP architecture with namespaces
* Full sanitization & validation

== Installation ==

1. Upload the `dev-chefpress-woocommerce` folder to `/wp-content/plugins/`
2. Activate the plugin through the 'Plugins' menu in WordPress
3. Create or edit a WooCommerce product
4. Change the product type to "Recipe Product"
5. Find the "🍳 Recipe Builder" tab in the product data panel
6. Fill in your recipe details and publish

== Frequently Asked Questions ==

= Does this require ACF or any other plugin? =
No. Dev ChefPress uses only native WordPress APIs.

= Can I override the frontend templates? =
Yes. Copy any template from `/templates/` to `{your-theme}/chefpress/` and edit freely.

= Is it compatible with WooCommerce HPOS? =
Yes, fully compatible with High-Performance Order Storage.
